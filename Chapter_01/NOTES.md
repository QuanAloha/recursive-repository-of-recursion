## Chapter One Questions

1) In general, what is a recursive thing?

> A recursive thing is a funciton or code that calls itself to solve a problem. 

2) In programming, what is a recursive function?

> A recursive function is a function that calls itself to solve a problem. 

3) What four features do functions have?

> Functions have inputs, return cases, a body, and a place to return to in the code that called it. 

4) What is a stack?

> A stack is the computers way of knowing what problems to solve first. it is how it keeps track of what code to call next. 

5) What are the terms for adding and removing values to the top of a stack?

> Pushing and popping

6) Say you push the letter J to a stack, then push the letter Q, then pop the stack, then push the letter K, then pop the statck again. What does the stack look like?

> The stack just has a J

7) What is pushed and popped onto the call stack?

> Function calls and arguments. This is called a frame. It contains the local variables as well as the call. 

8) What causes a stack overflow to happen?

> A stack overflow happens when there are too many funciton calls/frames for the stack to take care of. 

9) What is a base case?

> This is the logical case that tells a recursive path to start unraveline and recursin gbackwards. 

10) What is a recursive case?

> This is the case where the recursive function needs to call itself again. 

11) How many base cases and recursive cases to recursive funcitons have?

> As many as they want. but the less the better and atleast one of each. 

12) What happens if a recursive function has zero base cases?

> It will never recurse back and always throw stack overflows. 

13) What happens if a recursive function has zero recursive cases?

> Its just a normal function at that point.
